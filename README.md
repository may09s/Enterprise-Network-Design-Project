# Enterprise Network Design Project

## Overview

This project presents the design, documentation, and Cisco Packet Tracer implementation of a secure and scalable enterprise network. It includes the network architecture, addressing plan, device inventory, configuration, verification evidence, and project presentation materials.

## Network Features

- OSPF dynamic routing
- HSRP gateway redundancy
- VLAN segmentation
- DHCP services
- VPN connectivity
- Quality of Service (QoS)
- Voice VLAN and VoIP support
- Redundant core design

## How to Review the Project

1. Start with `Documentation.docx` for the overall design and implementation details.
2. Review `Addressing_Table.xlsx` and `Device List.docx` for the addressing plan and equipment inventory.
3. Open `Logical diagram.docx` and `Physical Diagram.docx` to understand the network topology.
4. Open `Netconfig Solutions.pkt` in Cisco Packet Tracer to inspect and test the implementation.
5. Use the files in `Screenshots/` to compare configuration and verification results.
