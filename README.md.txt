# Enterprise Network Design Project

## Project Overview
This project presents the design and implementation of a secure, scalable enterprise network using Cisco technologies.

## Features
- OSPF Routing
- HSRP Redundancy
- DHCP Services
- VPN Connectivity
- QoS Configuration
- VLAN Segmentation

## Tools Used
- Cisco Packet Tracer
- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint

## Repository Contents
- Documentation
- Physical Diagram
- Logical Diagram
- Device List
- Addressing Table
- Gantt Chart
- Packet Tracer Simulation
- Verification Screenshots
